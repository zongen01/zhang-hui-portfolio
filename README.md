## 计算口径

访客支付转化率 = 支付买家数 / 访客数；平均订单金额 = 支付金额 / 支付订单数；ROAS = 广告归因收入 / 广告花费。均应使用同一统计周期；ROAS 不代表利润率。分母为零时显示破折号。
